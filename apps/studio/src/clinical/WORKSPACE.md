# Clinical Workspace

Layout (resizable + persistent):

1. Header — Case / Patient / Project / Import / Save / Undo / Redo / Preferences / Help
2. Toolbar — registered clinical tools
3. Left panel — Case (enabled); Scene/Objects/Preparation/Segmentation/Treatment/Manufacturing disabled
4. Viewport — Viewport Runtime via `ClinicalDocumentHost`
5. Right inspector — Inspector / Properties / Selection / Camera / Display / Tool
6. Bottom — Notifications / Logs / Diagnostics / Import / Jobs
7. Status bar — clinical + viewport statistics

`ClinicalLayout` persists sizes, collapse state, and active tabs.

# Applications

Applications are composition roots. They assemble approved packages and native adapters but do not contain domain, renderer, geometry, or persistence policy.

The Studio Host lives at **`apps/studio`** (`@cad-studio/studio`, APP-001). Historical constitution text referred to this role as `apps/desktop` — see [ADR-0006](../docs/adr/0006-studio-host-apps-studio.md).
